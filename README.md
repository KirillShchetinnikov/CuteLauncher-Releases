# CuteLauncher — APK для Android TV

Публичный репозиторий установочных APK CuteLauncher. Здесь размещаются README и готовые APK в GitHub Releases. Исходники и ключи подписи сюда не загружаются.

## Скачать

Откройте [последний релиз](https://github.com/KirillShchetinnikov/CuteLauncher-Releases/releases/latest) и скачайте файл `CuteLauncher-…-universal-release.apk` из раздела Assets.

Требования: Android 12 или новее; процессор ARM32 (`armeabi-v7a`) или ARM64 (`arm64-v8a`). Универсальный APK поддерживает обе архитектуры.

## Установка и обновления

Разрешите установку из выбранного источника в настройках Android и откройте APK на телевизоре. Для обновления существующего приложения нужна та же подпись. Если Android сообщает о несовместимой подписи, не удаляйте приложение без резервной копии: удаление стирает его данные.

Начиная со сборки `1.0.0+3`, CuteLauncher проверяет стабильные релизы этого репозитория. В настройках приложения можно проверить обновление вручную или включить суточную проверку. Автопроверка по умолчанию выключена; скачивание запускает пользователь, установку подтверждает Android. Установки из Google Play используют обновления Google Play.

До установки проверяются контрольная сумма APK при её наличии, имя пакета, более высокий номер сборки и совпадение подписи.

## Публикация

APK размещаются только в Assets релизов. Стабильные теги имеют вид `v1.0.0+3` или `v1.1.0+4`; версия внутри APK должна соответствовать тегу. Каждая следующая сборка должна иметь больший `versionCode` и сохранять постоянный ключ подписи. Черновики и предварительные релизы автоматическая проверка не предлагает.

Файлы с ключами, паролями, учётными данными, настройками пользователя и тестовыми подписями не публикуются.
