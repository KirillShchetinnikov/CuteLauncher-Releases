## New releases

Starting with the next release, this file will describe new features, fixes,
and limitations that matter to users. Each entry includes the full release tag
with its build number and release date. This is the English translation of the
[Russian changelog](CHANGELOG_RU.md).

Historical APKs are available in [releases](https://github.com/KirillShchetinnikov/CuteLauncher-Releases/releases).
Entries for older versions have not been reconstructed retrospectively.
